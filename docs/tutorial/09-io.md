# Chapter 9: File and console I/O

This chapter covers reading from the console, writing to files, and working
with the filesystem.

## Console output

The `std.io` module provides formatted output:

```quazi
import std.io;

fn main() i32 {
    io.println("Hello, world!");            // with newline
    io.print("No newline here. ");          // without newline
    io.errln("Error message");              // stderr with newline
    io.err("Error without newline");        // stderr without

    // Formatted output with {} placeholders
    const name = "Quazi";
    const version = 1;
    io.println("Welcome to {} v{}", name, version);

    ret 0;
}
```

## Console input

```quazi
import std.io;

fn main() i32 {
    io.print("Enter your name: ");
    const name = io.readln();

    match name {
        Ok(text) => io.println("Hello, {}!", text),
        Err(_) => io.errln("Read error"),
    };

    ret 0;
}
```

`readln()` returns `Result[String, ReadError]`. `read()` reads until a
delimiter. `readkey()` reads a single keypress.

## File operations

### Reading files

```quazi
import std.fs;
import std.io;

fn main() i32 {
    const result = fs.read_to_string("data.txt");

    match result {
        Ok(content) => io.println("File contents:\n{}", content),
        Err(e) => io.errln("Cannot read file: {}", e.message()),
    };

    ret 0;
}
```

`read_to_string` validates UTF-8. Invalid bytes produce
`FsError.InvalidData`.

### Writing files

```quazi
import std.fs;
import std.io;

fn write_greeting(path: str) Result[usize, FsError] {
    const file = File.create(path)?;
    ret file.write_str("Hello from Quazi!\n");
}

fn main() i32 {
    match write_greeting("output.txt") {
        Ok(_) => io.println("Written successfully"),
        Err(e) => io.errln("Write error: {}", e.message()),
    };

    ret 0;
}
```

### File existence

```quazi
import std.fs;
import std.io;

fn main() i32 {
    if (fs.exists("data.txt")) {
        io.println("The file exists");
    }
    ret 0;
}
```

### Counting directory entries

```quazi
import std.fs;
import std.io;

fn main() i32 {
    match fs.count_entries("src/") {
        Ok(count) => io.println("{} entries", count),
        Err(e) => io.errln("Error: {}", e.message()),
    };
    ret 0;
}
```

## Error handling pattern

File operations return `Result[T, FsError]`. Common error variants:

- `FsError.NotFound` — file does not exist.
- `FsError.PermissionDenied` — insufficient permissions.
- `FsError.InvalidData` — file is not valid UTF-8.
- `FsError.Native(code)` — platform-specific error code.

Use `?` to propagate errors:

```quazi
fn load_config(path: str) Result[String, FsError] {
    const content = fs.read_to_string(path)?;
    ret Ok(content);
}
```

## Working with paths

```quazi
import std.os;
import std.io;

fn main() i32 {
    // Environment variables
    const home = os.env("HOME", "(not set)");
    io.println("Home: {}", home);

    ret 0;
}
```
