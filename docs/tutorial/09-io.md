# Chapter 9: File and console I/O

This chapter covers reading from the console, writing to files, and working
with the filesystem.

## Console output

The `std.io` module provides formatted output:

```quazi
import std.io;

fn main() i32 {
    io.println("Hello, world!");            // with newline
    io.print("No newline here. ");          // without newline
    io.eprintln("Error message");           // stderr with newline
    io.eprint("Error without newline");     // stderr without

    // Formatted output with {} placeholders
    const name = "Quazi";
    const version = 1;
    io.println("Welcome to {} v{}", name, version);

    ret 0;
}
```

## Console input

```quazi
import std.io;

fn main() i32 {
    io.print("Enter your name: ");
    const name = io.readln();

    match name {
        Ok(text) => io.println("Hello, {}!", text),
        Err(e) => io.eprintln("Read error: {}", e.message()),
    };

    ret 0;
}
```

`readln()` returns `Result[String, ReadError]`. `read()` reads until a
delimiter. `readkey()` reads a single keypress.

## File operations

### Reading files

```quazi
import std.fs;
import std.io;

fn main() i32 {
    const result = fs.read_to_string("data.txt");

    match result {
        Ok(content) => io.println("File contents:\n{}", content),
        Err(e) => io.eprintln("Cannot read file: {}", e.message()),
    };

    ret 0;
}
```

`read_to_string` validates UTF-8. Invalid bytes produce
`FsError.InvalidData`.

### Writing files

```quazi
import std.fs;

fn main() i32 {
    const result = fs.write("output.txt", "Hello from Quazi!\n");

    match result {
        Ok(_) => io.println("Written successfully"),
        Err(e) => io.eprintln("Write error: {}", e.message()),
    };

    ret 0;
}
```

### File metadata

```quazi
import std.fs;

fn main() i32 {
    match fs.metadata("data.txt") {
        Ok(meta) => {
            io.println("Size: {} bytes", meta.size());
        },
        Err(e) => io.eprintln("Error: {}", e.message()),
    };
    ret 0;
}
```

### Directory listing

```quazi
import std.fs;

fn main() i32 {
    match fs.read_dir("src/") {
        Ok(entries) => {
            for entry : entries {
                io.println("  {}", entry);
            }
        },
        Err(e) => io.eprintln("Error: {}", e.message()),
    };
    ret 0;
}
```

## Error handling pattern

File operations return `Result[T, FsError]`. Common error variants:

- `FsError.NotFound` — file does not exist.
- `FsError.PermissionDenied` — insufficient permissions.
- `FsError.InvalidData` — file is not valid UTF-8.
- `FsError.Native(code)` — platform-specific error code.

Use `?` to propagate errors:

```quazi
fn load_config(path: str) Result[String, FsError] {
    const content = fs.read_to_string(path)?;
    ret Ok(content);
}
```

## Working with paths

```quazi
import std.os;

fn main() i32 {
    // Current working directory
    const cwd = os.cwd();
    io.println("Working directory: {}", cwd);

    // Environment variables
    const home = os.env("HOME");
    io.println("Home: {}", home);

    ret 0;
}
```
