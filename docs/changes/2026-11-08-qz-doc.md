# `qz doc`

Audience: language users and library maintainers.

`qz doc [-o DIR]` writes one Markdown page per project source (default
`<out_dir>/doc`) plus an index `README.md`. Each page lists public functions,
structs, enums, traits, type aliases and public methods (`Type.method`), with
the signature copied from source (function bodies omitted; type declarations
complete) and the `//` comment block directly above the declaration as its
documentation; attributes between the comment and the declaration are skipped.

Platform-specific declarations selected by `@cfg` appear once per variant.
The command parses each file on its own and does not type-check it.

Verification: `apidoc` unit tests cover public/private filtering, methods,
comments and attributes; generating the `std` reference produces 24 pages.
